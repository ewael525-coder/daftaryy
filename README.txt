طريقة بناء APK بدون Android Studio:
1) اعمل حساب على github.com واعمل Repository جديد.
2) ارفع كل محتويات الفولدر ده (بما فيهم فولدر .github).
3) ادخل تبويب Actions > Build Android APK > Run workflow.
4) بعد ~5 دقايق نزّل الملف من Artifacts (daftary-apk) وفك الضغط، هتلاقي app-debug.apk.
5) انقله للموبايل وثبّته (فعّل "التثبيت من مصادر غير معروفة").

للآيفون بدون Mac: ارفع فولدر www على Netlify أو GitHub Pages، وافتح الرابط
في Safari > مشاركة > "إضافة إلى الشاشة الرئيسية".
